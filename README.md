# EcoBazar – Sustainable Marketplace

EcoBazar is a web and mobile application that helps users make eco-conscious shopping decisions by showing the carbon footprint of products and providing sustainable alternatives.

---

## 🌟 Features

- **User & Seller Management:** Admin can approve, reject, or manage users and sellers.  
- **Seller Dashboard:** Sellers can manage their products, view eco-ratings, track sales, and monitor carbon footprint impact.  
- **Buyer Dashboard:** Buyers can browse products, view carbon footprint information, and get eco-friendly product suggestions.  
- **Product Oversight:** Admin can monitor all products, eco-ratings, and carbon footprints.  
- **Carbon Footprint Analytics:** Dashboard showing CO2 reduction and eco-compliance.  
- **Admin Dashboard:** Real-time stats on users, sellers, products, and environmental impact.  
- **Secure Authentication:** Login/logout with role-based access.  

---

## 🛠 Technologies

- **Frontend:** React, TypeScript, TailwindCSS, Vite  
- **Backend:** Spring Boot, Java  
- **Database:** MySQL  
- **Version Control:** Git & GitHub
